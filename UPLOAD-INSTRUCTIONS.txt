ARTHUR'S HOLIDAY PASSPORT — WEBSITE UPDATE

To publish this update on GitHub Pages:
1. Extract this ZIP on a computer or in a file manager that can extract ZIP files.
2. Open the extracted folder. Select its contents (index.html, app.js, styles.css, assets, and the other site files).
3. On GitHub, open the repository's Upload files page and upload those extracted contents into the repository root. Keep the assets folder and the supabase folder in their existing folder structure.
4. Commit the upload to the main branch.
5. Refresh the live page after GitHub Pages finishes deploying. If it still shows an old copy, close the tab and reopen the page or clear the browser site data.

The account setup UI is in the site files. The matching circus-admin Edge Function has already been deployed to the connected Supabase project. The source is also included under supabase/functions/circus-admin for repository history.
